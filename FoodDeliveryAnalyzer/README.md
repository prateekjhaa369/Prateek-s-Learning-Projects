# Food Delivery Order Analyzer

A small Java console project built to practice Stream collection and categorization using a realistic food-delivery scenario.

## Concepts Applied

* Java Streams
* `collect()`
* `Collectors.groupingBy()`
* `Collectors.partitioningBy()`
* `Map`
* `List`
* Method references
* Generics

## What It Does

The application processes a collection of food-delivery orders and:

1. Groups orders by restaurant.
2. Partitions orders into high-value and normal-value orders based on a given amount threshold.

The project is intentionally small and focuses on applying Java Stream Collectors to a practical problem rather than building a complete food-delivery system.
