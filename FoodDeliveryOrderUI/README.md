# Food Delivery Order UI

A small Java Swing project that models the UI structure of a food-delivery order screen.

## What I Practiced

This project applies basic Java Swing GUI concepts:

* `JFrame`
* `JPanel`
* `JLabel`
* `JTextField`
* `JButton`
* Layout Managers
* `Color`
* `Font`

## Real-World Context

Food-delivery applications need an interface where users can view or enter information such as the restaurant, food item, quantity, price, and delivery address.

This project focuses only on constructing that interface.

## Current Scope

This is a GUI-construction project. It does **not** yet contain button actions or order-processing logic.

Event handling will be added later after learning Java event handling.

## Concepts Applied

The main goal was to take the GUI concepts learned in Java and apply them to a small real-world flavored problem instead of building only isolated examples.
